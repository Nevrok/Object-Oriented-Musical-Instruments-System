# Object-Oriented Musical Instruments System

Консольное приложение на C++ для управления магазином струнных музыкальных инструментов.

## Возможности

- добавление акустических гитар, электрогитар и бас-гитар;
- просмотр списка инструментов;
- удаление одного или всех инструментов;
- сохранение списка в файл `store.txt`;
- загрузка списка из файла `store.txt`;
- автозаполнение 12 инструментами из `instruments_data.txt`;
- подсчёт инструментов по типам;
- поиск инструмента по бренду;
- изменение бренда и количества струн;
- настройка и воспроизведение инструментов;
- зарядка электронных инструментов и расход заряда при воспроизведении;
- сравнение мощности электронных инструментов;
- демонстрация работы с покупателем и его инвентарём;
- переключение русского и английского языков клавишей `TAB`.

## Требования

- Windows;
- Microsoft Visual Studio с компонентами разработки классических приложений на C++;
- стандарт C++17 или совместимый стандарт, заданный в файле проекта;
- поддержка Windows Multimedia API для воспроизведения звуков.

## Сборка в Visual Studio

1. Откройте файл `Object-Oriented-Musical-Instruments-System.vcxproj`.
2. Выберите конфигурацию `Debug` или `Release`.
3. Выберите платформу `x64` или платформу, заданную в конфигурации проекта.
4. Выполните `Build` → `Build Solution`.
5. Запустите приложение из Visual Studio или из каталога, указанный в настройках вывода проекта.

Рабочим каталогом приложения должен быть каталог, содержащий файлы данных. Если файл не найден рядом с исполняемым файлом, программа пытается открыть его из текущего рабочего каталога.

## Управление

Главное меню:

| Клавиша |                 Действие                   |
|---------|--------------------------------------------|
|   `1`   |          Добавить инструмент               |
|   `2`   |        Показать все инструменты            |
|   `3`   |       Очистить список инструментов         |
|   `4`   |     Продать или удалить один инструмент    |
|   `5`   |       Сохранить список в `store.txt`       |
|   `6`   |       Загрузить список из `store.txt`      |
|   `7`   | Показать количество инструментов по типам  |
|   `8`   |          Найти инструмент по бренду        |
|   `9`   |            Открыть меню покупателя         |
|   `0`   |       Выбрать инструмент для управления    |
|   `F`   | Заполнить список из `instruments_data.txt` |
|   `TAB` |               Переключить язык             |
|   `ESC` |          Вернуться назад или выйти         |

В отдельных меню используются клавиши `1`–`9` согласно отображаемым пунктам. При вводе текста клавиша `ESC` отменяет текущий ввод.

## Файлы данных

### `instruments_data.txt`

Файл автозаполнения. Каждая строка описывает один инструмент, поля разделены точкой с запятой.

Формат акустической гитары:

```text
A;бренд;количество струн;группа;материал;цвет канта;размер;цвет корпуса;материал грифа;материал струн
```

Формат электрогитары:

```text
E;бренд;количество струн;группа;материал;мощность;заряд;количество звукоснимателей
```

Формат бас-гитары:

```text
B;бренд;количество;группа;материал;мощность;заряд;количество струн
```

Пустые строки и строки, начинающиеся с `#`, игнорируются. Ошибочные строки пропускаются.

В текущем файле находятся 12 записей: по 4 инструмента каждого типа.

### `store.txt`

Файл сохранённого списка. Он создаётся и обновляется через пункт `5` главного меню. Загрузка выполняется через пункт `6`.

Файл использует внутренний многострочный формат `InstrumentStore`: сначала указывается количество записей, затем данные каждого инструмента и его специфические параметры.

## Архитектура проекта

- `main.cpp` — главное меню, ввод пользователя, автозагрузка и сценарии работы приложения;
- `StringInstruments.h/.cpp` — базовый класс струнных инструментов;
- `AcousticGuitar.h/.cpp` — акустическая гитара;
- `ElectricGuitar.h/.cpp` — электрогитара;
- `BassGuitar.h/.cpp` — бас-гитара;
- `ElectronicDevice.h/.cpp` — общая логика мощности, батареи и зарядки;
- `InstrumentStore.h/.cpp` — хранение, поиск, добавление, удаление, загрузка и сохранение инструментов;
- `Customer.h/.cpp` — покупатель и его инвентарь;
- `Localization.h/.cpp` — русские и английские тексты интерфейса;
- `instruments_data.txt` — данные автозаполнения;
- `store.txt` — сохранённая база инструментов;
- `README.md` — документация проекта.

## Основные принципы ООП

В проекте используются:

- наследование: специализированные гитары наследуются от `StringInstruments`;
- множественное наследование: `ElectricGuitar` и `BassGuitar` используют `ElectronicDevice`;
- полиморфизм через виртуальные методы `Play`, `SetUp`, `Tune`, `Print` и `GetTypeName`;
- инкапсуляция полей классов и публичные методы доступа;
- перегрузка операторов `++`, `--`, `!` и `==`;
- динамическое определение типа через `dynamic_cast`.

## Звуковые файлы

Звуковые файлы не встраиваются в исполняемый файл. Их необходимо самостоятельно добавить в каталог, из которого запускается приложение. Надёжнее всего поместить их непосредственно рядом с `.exe` и настроить этот каталог как рабочий каталог отладки в Visual Studio.

Программа использует Windows MCI (`mciSendStringW`) и открывает MP3-файлы как устройства типа `mpegvideo`. Имена файлов чувствительны к соответствию строкам в коде и должны быть указаны без переименования:

|          Файл             |      Используется        |                      Когда запускается                                   |
|---------------------------|--------------------------|--------------------------------------------------------------------------|
| `acousticguitarsound.mp3` | звук акустической гитары | при выборе `Play` для акустической гитары; повторно после разрыва струны |
| `electricguitarsound.mp3` | звук электрогитары       | при выборе `Play` для электрогитары                                      |
| `bassguitarsound.mp3`     | звук бас-гитары          | при выборе `Play` для бас-гитары                                         |
| `brokestringsound.mp3`    | звук разрыва струны      | при нажатии `!` во время игры на акустической гитаре                     |

### Требования к файлам

- формат — MP3;
- имена и расширения должны совпадать с указанными выше;
- файлы должны быть доступны приложению по относительному пути;
- для текущей реализации рекомендуется использовать короткие имена без пробелов и специальных символов;
- каждый файл должен быть доступен для чтения текущему пользователю Windows;
- длительность `brokestringsound.mp3` желательно согласовать с задержкой около 6 секунд, используемой после разрыва струны.

### Как добавить музыку

1. Подготовьте четыре MP3-файла.
2. Переименуйте их точно в соответствии с таблицей.
3. Скопируйте файлы в каталог с исполняемым файлом приложения, например `x64\Debug\` или `x64\Release\`.
4. В Visual Studio проверьте свойство проекта `Debugging` → `Working Directory`, если приложение запускается из среды разработки.
5. Запустите приложение и выберите управление инструментом → `Play`.

Перед открытием каждого файла код выполняет проверку существования. Если файл отсутствует или не открывается, в консоль выводится предупреждение `Sound file not found`, а остальные функции приложения продолжают работать. При ошибке Windows MCI дополнительно выводится текст ошибки MCI.

Во время воспроизведения:

- акустическая гитара играет до нажатия клавиши выхода или `!`;
- при нажатии `!` основной звук останавливается, запускается звук разрыва струны, уменьшается количество струн, затем основной звук запускается снова, если струны ещё остались;
- электрогитара и бас-гитара расходуют заряд батареи во время воспроизведения;
- при завершении или досрочной остановке вызываются команды MCI `stop` и `close`, поэтому аудиофайл освобождается корректно.

Для работы со звуком проект подключает системную библиотеку `winmm.lib`. Это Windows-зависимая часть приложения; на других операционных системах текущая реализация воспроизведения работать не будет.

## Ограничения

- максимальная вместимость магазина задаётся при создании `InstrumentStore` и в текущей версии равна 20;
- для названий и брендов используется проверка допустимых символов;
- количество струн не может быть отрицательным;
- заряд электронного инструмента ограничен диапазоном от 0 до 100 процентов;
- для корректной загрузки нельзя менять порядок и количество полей в строках файлов данных;
- файл `store.txt` перезаписывается при сохранении.
